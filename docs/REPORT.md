# 산출물 보고 — Second Read (클로드코드 버전)

## v0.4.0 (2026-10-06, 디렉터 모드: 게임성·완성도 패스)

### "이 슬라이스를 지금 유료로 팔 수 있는가?" — 아직 아니다 (근접)
- 된 것: 추리가 실제로 가능한 규칙(단서 읽는 플레이가 무작위보다 승률 +27%p), 판을 넘는 기억과 예측 대결, 스토어에 올릴 수 있는 일러스트·키 아트, 효과음, 첫 판 안내.
- 막는 것: ① 실제 ChatGPT 로그인 상태의 대사 품질·속도 미검증 ② 사람 플레이테스트 0회 ③ 서명 안 된 빌드(설치 이탈)·Windows 실기 미확인. 이 셋이 풀리기 전엔 유료 판매 품질이라고 말할 수 없음.

### 바뀐 것
| 항목 | 내용 |
| --- | --- |
| 공정한 단서 | 라이벌의 의심 점수를 "사실 근거" 단위로 계산해, 모든 의심·감싸기에 근거 한 줄을 붙임(없으면 솔직히 "감"). 마피아 규칙: 동료에게 투표·의심 안 함, 80% 몰표, 낮에 자기편을 의심한 사람을 밤에 노림(60%). 시민 라이벌은 밤 희생자가 의심했던 사람, 마피아와 같은 표, 말 바꾼 표를 근거로 씀 |
| 추궁하기 | 싱글, 하루 1회. 투표 계획 / 역할 / 의심 이유. 시민은 약속한 표를 지키고, 마피아는 절반은 다른 이름을 대고 계획대로 찍음 → "말 바꿈"이 공개 사실이 됨 |

| 군더더기 축소 | 2라운드는 의심받은 사람·예언자 주장만 말함. 관망 대사는 "레온·미오 지켜보는 중" 한 줄로 묶음 |
| 아트 | 캐릭터 6명 + 플레이어 초상화, 타이틀 키 아트(일관된 일러스트 스타일). 스크린샷 6장 `docs/screenshots/` |
| 사운드 | Kenney CC0 효과음 13종(클릭·대사·투표·재판·처형·밤·예측·추궁·승패), 설정에서 끌 수 있는 생성형 배경 패드(기본 꺼짐) |
| 첫 판 안내 | 결정 종류마다 한 번씩 짧은 팁(말하기·추궁·투표·최후 변론·찬반·밤·예측), 3판 이후 표시 안 함 |

### 아직 검증 안 된 것
- 실제 ChatGPT 로그인으로 대사 품질·지연·한도 동작.
- 사람 플레이테스트(재미, "들켰다" 체감, 추궁의 쓸모).
- Windows 실기 실행, mac 공증(ad-hoc 서명만).
- n빵 방식의 Sign in with ChatGPT 이용 조건 적합성, 중계 서버의 호스팅 제한 해당 여부.
- 배경음은 단순 생성 패드라 상업 품질이 아님(작곡 음원 필요).
- 멀티 2라운드는 의심받은 사람 위주로만 AI가 말해서, 사람 메시지 비율이 높아질 수 있음(정체 노출 위험, 미측정).
- 멀티에서 사람 예언자는 대상 없는 "내가 진짜 예언자" 주장을 문장으로만 할 수 있고 집계 칩은 지원 안 함.

| 항목 | 내용 |

| 싱글: 대화 | 하루 2라운드. 2라운드에서 라이벌이 직전 라운드 의심에 부인하거나 되받아침. 플레이어가 입력한 문장이 다음 AI 호출의 오늘 대화에 포함되어 반응 가능 |
| 멀티 | 사람 1~4 + AI 4, 무작위 닉네임, 라운드별 동시 공개, 동시 투표, 끝나면 정체 공개. 사람 2명이면 6석, 3명이면 7석, 4명이면 8석(마피아 2) |
| 멀티: AI 대사 비용 | 로그인한 참가자들이 AI 4명을 나눠 맡아 자기 플랜으로 생성(n빵). 늦으면 8초 뒤 미리 쓴 대사로 대체(같은 방에서 같은 문장 반복 안 함) |
| 멀티: 말투 학습 | 판 종료 후 사람 메시지에서 말투 특징과 예문(숫자·링크·@ 제외, 최대 30개)을 로컬에 저장해 다음 판 프롬프트에 사용. 스킵 비율도 학습해 AI 스킵 빈도에 반영 |
| 최후 변론 | 투표 1위가 마지막 한마디 후 찬반 투표(찬성 과반이어야 처형). AI 찬반도 기억(텔) 반영, 기억 때문에 바뀐 찬반은 결과 화면에 '최후 판결'로 표시. 싱글은 AI가 재판받을 때 AI 호출 1회 추가 |
| 자기 변호 | '나는 아니다'를 항상 선택 가능. 의심받은 뒤 해명하면 의심이 조금 줄고, 먼저 부인하면 조금 수상해짐. 새 텔 '의심받으면 해명'(세라) |
| 새 텔 | 의심한 사람에게 실제 투표(말·표 일치), 라운드 건너뛰기. 동시 투표인 멀티에서도 모든 라이벌이 볼 텔이 있도록 |
| 중계 서버 | Cloudflare Worker + Durable Object(SQLite, 무료 플랜용). 로컬(`wrangler dev`)에서만 검증, 배포 안 함 |

### v0.2 남은 확인 사항

- 실제 ChatGPT 로그인 상태의 AI 대사 품질·속도(특히 멀티에서 8초 안에 오는지)는 아직 실측하지 못함.
- 다른 사람 게임의 AI 대사를 내 플랜으로 생성하는 n빵 방식이 Sign in with ChatGPT 오픈소스 이용 조건에 맞는지 확인 필요.
- 원격 호스팅 제한이 메시지 중계 서버에도 적용되는지는 레나 님 판단 필요(서버는 토큰을 다루지 않음).
- 멀티에서 템플릿으로 대체된 AI 대사 비율(사람/AI 구별 단서)을 판마다 측정 기록에 남김. 실제 로그인 상태에서 이 비율을 봐야 함.
- 배포된 v0.1.0 빌드에는 v0.2 기능이 없음. 서버 배포 전이라 새 릴리스는 만들지 않았음.

## 성공 기준 충족 여부

| 기준 | 판정 | 근거 |
| --- | --- | --- |
| 3~5판째 AI가 지난 판 습관을 근거로 처음 지목 | **시뮬레이션상 충족** | 일관된 습관: 3~5판 99%(대부분 4판). 자연스러운 경향(마피아 65% vs 시민 30%): 3~5판 76% |
| 지목이 실제 판단(투표)에 영향 | **충족** | 일관된 습관의 마피아가 3판 이후 처형당하는 비율: 기억 켬 86% vs 끔 67%. 기억이 투표를 바꾼 첫 판: 3~5판 86% |
| 기억 끄면 체감 차이 없음 → 실패 조건 | **회피** | 끄면 근거 대사·투표 변화가 구조적으로 0(테스트로 보장). 습관이 없는 플레이어(무작위)는 켬/끔 차이가 없음(62% vs 62%) — 의도된 동작 |
| 근거 없는 기억 발화 금지 | **충족(구조적)** | 모델은 통계를 못 보고 코드가 만든 근거 문장만 받음. 검증기가 근거 ID·숫자·대상·'지난 판' 언급을 검사하고 실패 시 템플릿으로 대체. 근거 문장의 숫자가 저장 기록과 일치하는지 테스트 |
| 가짜 텔로 속이면 기록·보상 | **충족** | 4판까지 일관되다가 5판부터 마피아일 때 시민처럼 행동한 플레이어: 4판엔 기억 켬 84% vs 끔 66%로 잡히다가, 5판엔 43% vs 60%로 역전(기억이 오히려 속음). 이 경우가 '속임 성공'으로 기록되고 누적 점수로 표시됨. 이후 판에서 라이벌이 새 습관을 학습해 효과가 줄어듦(8판 48% vs 55%) |
| 플레이어가 "들켰다" 느끼고 행동을 바꾸는가 | **미검증** | 실제 사람 플레이테스트가 필요. 아래 측정 기능으로 수집 가능 |

## 수치

| 항목 | 값 | 출처 |
| --- | --- | --- |
| 판당 AI 호출 | **최대 3회** (1일차 발언 1, 2일차 발언 1, 종료 한마디 1) | 설계 |
| 판당 입력 토큰 | **약 2,100** (호출당 최대 약 900) | o200k 토크나이저로 실제 프롬프트 600판 측정. 판이 쌓여도 증가 없음(1판 2,095 → 6판 2,187) |
| 판당 출력 토큰 | 약 600~900 + 추론 토큰(low) | 추정. 실측은 로그인 후 앱에서 기록됨 |
| 1판 소요 시간 | 약 2~4분 | UI 지연 합산 추정 + 오프라인 자동 플레이 |
| 1회 AI 응답 시간 (첫 토큰 / 완료) | **실측 못 함** | 실제 ChatGPT 계정 로그인이 필요. 앱 설정 → 측정에서 판별·호출별 첫 토큰까지 / 완료까지 / 토큰을 자동 기록하고 JSON으로 내보낼 수 있음. AI 응답이 10초를 넘으면 템플릿으로 대체되어 판이 멈추지 않음 |
| 텔이 처음 드러나기까지 | **3판째부터 가능, 보통 4판째** | 1판 시민 → 2판 마피아 → 3판 시민 → 4판 마피아로 역할을 고정 배정. 두 역할을 1번씩 본 3판째부터 텔이 성립하고, 마피아 쪽 신호로 지목되는 건 주로 4판째 |

## 구현 판단 요약

- 엔진: Electron + 순수 JS(빌드 단계 없음). 5인(당신+AI 4), 마피아1·예언자1·시민3, 최대 2일.
- 텔 6종: 가장 먼저 투표 / 표 몰린 쪽 편승 / 첫 마디 의심 / 첫 마디 관망 / 나를 의심한 사람에게 투표 / 나를 의심한 사람이 밤에 제거됨. 전부 클릭 데이터에서 추출.
- 성격(말투·공격성·투표 무작위성·원한)과 텔 종류(무엇을 지켜보는가)를 분리. 라이벌마다 지켜보는 텔이 다름.
- 텔 모델: 역할별 빈도(최근 판 가중, 감쇠 0.8) + 라플라스 평활 → 우도비. 두 역할 모두 관측 있고 차이 0.25 이상일 때만 사용. 합계 상한 있음 → 확률적, 틀릴 수 있음.
- 마피아 AI도 당신의 실제 텔을 근거로 시민인 당신을 몰아갈 수 있음(역이용).

## 발견한 제약

1. **실 계정 테스트 불가**: Sign in with ChatGPT 로그인과 Responses 스트리밍은 문서대로 구현했지만, 실제 계정으로 왕복 검증은 하지 못했습니다. 첫 실행에서 확인할 것: 등록 콜백에 `client_id`가 오는지, `/v1/models` 응답 형태(`models[].slug`), `text.format` JSON 스키마와 `reasoning.effort` 수용 여부(거부 시 자동 제거 후 재시도하도록 처리).
2. **모델 선택**: 계정별 모델 목록에서 이름에 "mini"가 들어간 모델을 기본으로 고릅니다. 없으면 첫 모델. 설정에서 변경 가능. 느린 모델이면 템플릿 대체가 늘어납니다.
3. **macOS**: Apple Developer 계정 보유 여부를 확인하지 못해 ad-hoc 서명으로 빌드했습니다. 다운로드 사용자는 "그래도 열기" 절차가 필요합니다. 계정이 있으면 README의 공증 명령으로 다시 빌드하세요.
4. **Windows**: 코드 서명 없음 → SmartScreen 경고. Windows 실기 실행 미확인. 앱 아이콘은 기본 Electron 아이콘.
5. **itch.io 앱 실행**: itch 앱 샌드박스에서는 127.0.0.1 콜백이 막힐 수 있어 직접 실행을 안내했습니다.
6. **외장 디스크 빌드**: 프로젝트가 있는 외장 볼륨에서 mac universal 병합이 asar 읽기 오류로 실패해 로컬 디스크로 출력해야 했습니다.
7. **용량**: mac universal 약 230MB, Windows 약 110~150MB (Electron 기본 크기).
8. **사람 플레이테스트 없음**: 성공 기준의 핵심(들켰다는 체감, 행동 변화)은 시뮬레이션으로 대신했습니다. 1차 배포 후 측정 기록(판 수, 지목 횟수, 읽힘/속임)을 받아 보는 것을 권합니다.
