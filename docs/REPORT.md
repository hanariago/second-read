### v0.2 남은 확인 사항

- 실제 ChatGPT 로그인 상태의 AI 대사 품질·속도(특히 멀티에서 8초 안에 오는지)는 아직 실측하지 못함.

- 원격 호스팅 제한이 메시지 중계 서버에도 적용되는지는 레나 님 판단 필요(서버는 토큰을 다루지 않음).
- 배포된 v0.1.0 빌드에는 v0.2 기능이 없음. 서버 배포 전이라 새 릴리스는 만들지 않았음.

## 성공 기준 충족 여부

| 기준 | 판정 | 근거 |
| --- | --- | --- |
| 3~5판째 AI가 지난 판 습관을 근거로 처음 지목 | **시뮬레이션상 충족** | 일관된 습관: 3~5판 99%(대부분 4판). 자연스러운 경향(마피아 65% vs 시민 30%): 3~5판 76% |
| 지목이 실제 판단(투표)에 영향 | **충족** | 일관된 습관의 마피아가 3판 이후 처형당하는 비율: 기억 켬 86% vs 끔 67%. 기억이 투표를 바꾼 첫 판: 3~5판 86% |
| 기억 끄면 체감 차이 없음 → 실패 조건 | **회피** | 끄면 근거 대사·투표 변화가 구조적으로 0(테스트로 보장). 습관이 없는 플레이어(무작위)는 켬/끔 차이가 없음(62% vs 62%) — 의도된 동작 |
| 근거 없는 기억 발화 금지 | **충족(구조적)** | 모델은 통계를 못 보고 코드가 만든 근거 문장만 받음. 검증기가 근거 ID·숫자·대상·'지난 판' 언급을 검사하고 실패 시 템플릿으로 대체. 근거 문장의 숫자가 저장 기록과 일치하는지 테스트 |
| 가짜 텔로 속이면 기록·보상 | **충족** | 4판까지 일관되다가 5판부터 마피아일 때 시민처럼 행동한 플레이어: 4판엔 기억 켬 84% vs 끔 66%로 잡히다가, 5판엔 43% vs 60%로 역전(기억이 오히려 속음). 이 경우가 '속임 성공'으로 기록되고 누적 점수로 표시됨. 이후 판에서 라이벌이 새 습관을 학습해 효과가 줄어듦(8판 48% vs 55%) |
| 플레이어가 "들켰다" 느끼고 행동을 바꾸는가 | **미검증** | 실제 사람 플레이테스트가 필요. 아래 측정 기능으로 수집 가능 |

## 구현 판단 요약

- 엔진: Electron + 순수 JS(빌드 단계 없음). 5인(당신+AI 4), 마피아1·예언자1·시민3, 최대 2일.
- 텔 6종: 가장 먼저 투표 / 표 몰린 쪽 편승 / 첫 마디 의심 / 첫 마디 관망 / 나를 의심한 사람에게 투표 / 나를 의심한 사람이 밤에 제거됨. 전부 클릭 데이터에서 추출.
- 성격(말투·공격성·투표 무작위성·원한)과 텔 종류(무엇을 지켜보는가)를 분리. 라이벌마다 지켜보는 텔이 다름.
- 텔 모델: 역할별 빈도(최근 판 가중, 감쇠 0.8) + 라플라스 평활 → 우도비. 두 역할 모두 관측 있고 차이 0.25 이상일 때만 사용. 합계 상한 있음 → 확률적, 틀릴 수 있음.
- 마피아 AI도 당신의 실제 텔을 근거로 시민인 당신을 몰아갈 수 있음(역이용).

## 발견한 제약

1. **실 계정 테스트 불가**: Sign in with ChatGPT 로그인과 Responses 스트리밍은 문서대로 구현했지만, 실제 계정으로 왕복 검증은 하지 못했습니다. 첫 실행에서 확인할 것: 등록 콜백에 `client_id`가 오는지, `/v1/models` 응답 형태(`models[].slug`), `text.format` JSON 스키마와 `reasoning.effort` 수용 여부(거부 시 자동 제거 후 재시도하도록 처리).
2. **모델 선택**: 계정별 모델 목록에서 이름에 "mini"가 들어간 모델을 기본으로 고릅니다. 없으면 첫 모델. 설정에서 변경 가능. 느린 모델이면 템플릿 대체가 늘어납니다.
3. **macOS**: Apple Developer 계정 보유 여부를 확인하지 못해 ad-hoc 서명으로 빌드했습니다. 다운로드 사용자는 "그래도 열기" 절차가 필요합니다. 계정이 있으면 README의 공증 명령으로 다시 빌드하세요.
4. **Windows**: 코드 서명 없음 → SmartScreen 경고. Windows 실기 실행 미확인. 앱 아이콘은 기본 Electron 아이콘.
5. **itch.io 앱 실행**: itch 앱 샌드박스에서는 127.0.0.1 콜백이 막힐 수 있어 직접 실행을 안내했습니다.
6. **외장 디스크 빌드**: 프로젝트가 있는 외장 볼륨에서 mac universal 병합이 asar 읽기 오류로 실패해 로컬 디스크로 출력해야 했습니다.
7. **용량**: mac universal 약 230MB, Windows 약 110~150MB (Electron 기본 크기).
8. **사람 플레이테스트 없음**: 성공 기준의 핵심(들켰다는 체감, 행동 변화)은 시뮬레이션으로 대신했습니다. 1차 배포 후 측정 기록(판 수, 지목 횟수, 읽힘/속임)을 받아 보는 것을 권합니다.
