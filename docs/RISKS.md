# 리스크와 대응책

마지막 갱신: 2026-10-06 (v0.5.0)

| # | 리스크 | 가능성 | 영향 | 대응책 (준비 완료) | 남은 확인 |
|---|---|---|---|---|---|
| R1 | 실제 ChatGPT 로그인 상태에서 대사가 늦거나, JSON 스키마·reasoning 옵션이 거부됨 | 중 | 높음 | 설정 → **AI 연결 점검**: 로그인·토큰 갱신·모델 목록·실제 스트리밍 응답을 1회로 확인하고 지연·수용된 옵션을 보여줌(토큰은 기록 안 함). reasoning은 minimal→low→생략 순으로 자동 강등, 스키마 거부 시 자동 제거. 10초 넘으면 미리 쓴 대사로 대체되어 판은 멈추지 않음 | 오너 계정으로 점검 1회 |
| R2 | 사용 한도 소진(Plus 5시간 한도 공유) | 중 | 중 | 판당 호출 상한 4회(평균 3.3회·입력 약 2,200 토큰), 결과 화면에 판별 사용량 표시, 한도 오류 시 "Manage usage" 안내 후 나머지는 미리 쓴 대사로 진행 | 실사용 측정 |
| R3 | 재미 미검증(사람 플레이테스트 0회) | 높음 | 높음 | **플레이테스트 키트**: 판마다 2문항 설문(읽혔다고 느꼈나 / 또 할래), 설정 → 기록 내보내기(JSON), `docs/PLAYTEST.md` 진행 가이드. 추리 가능성은 `npm run deduce`로 상시 측정(단서 플레이가 무작위보다 +27~36%p) | 지인 5~10명 × 5판 |
| R4 | 서명 안 된 빌드에서 설치 이탈 | 높음 | 중 | itch.io 안내문에 mac "그래도 열기"·Windows "추가 정보 → 실행" 절차. CI에 서명·공증 단계를 미리 넣어 둠: Secrets만 넣으면 서명 빌드가 나옴 | Apple Developer($99/년)·Windows 코드서명 인증서 |
| R5 | Windows 실기 미검증 | 중 | 높음 | CI(windows-latest)에서 실제 앱 셀프체크(메인 프로세스·브리지·오프라인 1판·OAuth 리스너)와 패키지 빌드·실행 확인 — **2026-10-06 통과** | Windows 실제 PC에서 사람 플레이 1회 |
| R6 | 멀티에서 AI 정체 노출(문체, 침묵 패턴) | 중 | 중 | 라운드 동시 공개, 무작위 닉네임, 말투 학습(로컬), 같은 방 같은 템플릿 반복 금지, 방에선 2라운드도 평소처럼 말함, 근거 칩·노트는 멀티에서 숨김, 템플릿 대체 비율을 판마다 기록 | 사람 2~4명 실플레이 |
| R7 | n빵(참가자 플랜으로 AI 대사 분담) | — | — | 오너 결정으로 유지. 담당자 이탈·한도 시 재배정 또는 미리 쓴 대사 | — |
| R8 | 중계 서버가 "원격 호스팅" 제한에 해당하는지 | 낮음 | 중 | 서버는 토큰을 다루지 않고 메시지만 전달(코드로 분리). 로컬 테스트만 진행, 배포 보류 | 배포 시 판단 |
| R9 | AI 대사가 근거 없는 기억을 말함 | 낮음 | 높음 | 모델은 근거 문장만 받고, 검증기가 근거 ID·숫자·"지난 판" 언급을 검사, 실패 시 템플릿 대체(테스트로 보장) | — |
| R10 | 밸런스 쏠림(인원별) | 중 | 중 | 인원별 역할 표(5/7/9) + 시뮬레이션: 무작위 시민 승률 29~49%, 단서 플레이 64~70%, 무작위 마피아 44~56%. CI가 추리 격차 10%p 미만이면 실패 처리 | 실플레이 승률 |
| R11 | 배경음 품질(생성 패드) | 높음 | 낮음 | 기본 꺼짐. 교체 가능한 구조(음원 파일로 바꾸면 됨) | 작곡 음원 확보 |
| R12 | 개인정보 | 낮음 | 높음 | 텔·말투·설문은 로컬 저장, 멀티 서버는 판 동안 메모리에만 보관, 숫자·링크·@ 포함 문장은 말투 예문에서 제외, 진단·내보내기에 토큰·이메일 없음 | — |
