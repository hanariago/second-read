# 플레이테스트 가이드

목표: "3~5판째에 라이벌이 내 버릇을 근거로 지목할 때 들켰다고 느끼고, 다음 판에서 일부러 행동을 바꾸는가"를 사람으로 확인한다.

## 준비 (진행자)
1. 테스터에게 최신 빌드(GitHub Releases)와 itch.io 안내문의 설치 절차를 보낸다.
2. ChatGPT Plus/Pro 테스터는 로그인 후 **설정 → AI 연결 점검**을 한 번 눌러 결과를 캡처해 달라고 한다(문제 진단용).
3. 인원은 기본 7명으로 시작한다.

## 진행 (테스터)
- 5판을 연달아 한다. 판마다 결과 화면의 두 질문에 답한다.
  - 이번 판, 라이벌에게 읽혔다고 느꼈나요? (네 / 조금 / 아니요)
  - 한 판 더 하고 싶나요? (네 / 아니요)
- 끝나면 **설정 → 플레이테스트 기록 내보내기**로 JSON 파일을 보낸다. 계정·토큰·이메일은 들어 있지 않다.

## 진행자가 볼 것
| 지표 | 기대 |
| --- | --- |
| 처음 "네(읽혔다)"가 나온 판 | 3~5판 |
| "읽혔다" 다음 판에서 예측을 깬 비율(`prediction.status = broken`) | 절반 이상 |
| "한 판 더" 비율 | 판이 갈수록 유지 또는 상승 |
| 시민일 때 승률 | 40~65% |
| 추궁 사용 여부(판마다 1회 가능) | 대부분 사용 |

## 짧은 인터뷰 (5분)
1. 가장 기억에 남는 장면은?
2. 라이벌이 근거를 댈 때 납득이 됐나, 억지 같았나?
3. 추궁 답변이 추리에 도움이 됐나?
4. 판 길이는 어땠나(짧다/적당/길다)?
5. 돈을 낸다면 얼마까지?
